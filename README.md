# 2026 日本北陸 Yam's Family Trip

手機優先的靜態行程網站，可直接部署至 GitHub Pages。

## 本機預覽

直接開啟 `index.html` 即可；也可以使用任何靜態檔案伺服器預覽。

## 部署至 GitHub Pages

1. 建立新的 GitHub repository。
2. 將本資料夾內的 `index.html`、`styles.css`、`script.js`、`robots.txt` 上傳到 repository 根目錄。
3. 在 repository 的 **Settings → Pages** 選擇從 `main` branch 的 `/ (root)` 發佈。
4. 網站已包含 `noindex` 與 `robots.txt`，請只將網址分享給同行家人。

> `noindex` 只能降低被搜尋引擎收錄的機率，不能形成密碼保護。GitHub Pages 網址本身仍是公開可存取的。

## 隱私

頁面不包含租車預約號碼、姓名、電話或 Email。若日後加入其他訂房資訊，也不要放入護照、付款或聯絡資料。
